# Code of Conduct

## Our standard

This project is a space for respectful, constructive technical and scientific
collaboration. Participants are expected to:

* be respectful and considerate towards others;
* give and receive criticism of ideas and code constructively;
* assume good faith and focus on what is best for the project and its users;
* represent scientific claims accurately and correct them when shown to be wrong.

Unacceptable behaviour includes harassment, discrimination, insults, personal attacks,
publishing others' private information, and other conduct that would reasonably be
considered inappropriate in a professional setting.

## Scope

This code applies in all project spaces (issues, pull requests, discussions) and when an
individual represents the project in public.

## Enforcement

Maintainers may edit or remove contributions that do not follow this code, and may
temporarily or permanently restrict participation. To report a concern, contact the
maintainer through the profile linked from the repository owner's GitHub page, or use
GitHub's reporting tools. Reports will be handled with discretion.

This code of conduct is a short statement written for this project and is inspired by
widely used community standards.
