# Changelog

All notable changes are documented here. The format follows Keep a Changelog and the project follows Semantic Versioning.

## [0.1.0] - 2026-11-14

### Added
- Initial release.
- Ten themes, including Forest, Cat, Terminal (programmer) and Repo Light/Dark (issue-list look), with a theme picker.
- Colour-coded labels: change a label's colour, rename it everywhere.
- Notes on tasks (`// note`) and a "Try it with sample tasks" first-run button.
- `npm run build` produces a single-file build that works from `file://`.
- Quick add with natural-language parsing of dates, times, priorities and tags, with a live preview of what was understood.
- Views: Today, Upcoming, Inbox, All, Done, plus tag filters.
- Keyboard-first interface, command palette, and a shortcut sheet.
- Inline editing that re-uses the quick-add parser.
- Undo and redo (100 steps), including after delete and complete.
- Drag-and-drop reordering.
- Focus mode with an optional 25-minute timer.
- Themes: auto, light, dark, sage, ink.
- JSON backup and import, Markdown export.
- Installable as a desktop app (PWA) with offline support; optional Electron shell.
- Cross-tab synchronisation and correct behaviour across midnight.
